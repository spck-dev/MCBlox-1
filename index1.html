What is a command block?

A Command Block is a special block that automatically runs commands. It lets you teleport players, give items, change the weather and much more.

How to get a command block?

Command Blocks cannot be crafted or found in Survival mode. Enable cheats and run this on your game's chat:

/give @s command_block

How to use a command block?

Open the command block interface by right-clicking it. Type your command into the text console. To power it, place a redstone activator next to it, such as a Button, Lever, or Pressure Plate.

Try your first command: Teleportation

Want to teleport yourself to specific coordinates? Type this command into your block, set it to "Needs Redstone", and press a button:

/tp @p 0 64 0
